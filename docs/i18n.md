# Interface languages

English · [繁體中文](i18n.zh-TW.md)

Inspector's interface comes in 繁體中文 (the base), English, 简体中文, 日本語 and 한국어.

## How it works

- The code is written in Traditional Chinese, and **the Chinese text itself is the translation key**:
  - Web: `t('新增規則')`, `t('第 {n} 步', { n })` (`web/src/i18n/index.ts`)
  - Server: `_("子腳本失敗")`, `_("第 {n} 步", n=3)` (`i18n/__init__.py`)
  - Module-level tables (e.g. step names) are marked with `N_("…")` and translated where shown, with `_()` or `tr(table)`.
- Keep a whole sentence in one text and put values in by name (`{name}`), so languages with another word order can move them. Never build a sentence from pieces.
- Plurals: a translation may write `{n|frame|frames}`; the first word is used when the value is 1 (e.g. `{n} {n|time|times}`). Chinese needs none.
- List separators and quotes are translated too: `_("、").join(...)` / `t('、')`, `_("「{x}」", x=…)` / `t('「{x}」', { x })`; in English they become `, ` and `"x"`.
- Catalogs:
  - Web `web/src/i18n/locales/<lang>.json`, server `i18n/locales/<lang>.json`, as `{"Chinese": "translation"}`.
  - A text a catalog lacks shows the Chinese, so a partial translation can already be used.
- Which language:
  - Web: each browser chooses (bottom of the sidebar, top right of the operation panel); every request carries `X-Lang`, so sentences the server builds follow it.
  - The runtime (run logs, notifications, chat bot replies): this computer's setting, `"language"` in `inspector.json`, changed under "Run › ⚙ Run settings".
  - The fixed words the runtime writes into its status file (stopped, paused, who pressed it…) are in the machine's language; the server turns them into the page's language with `i18n.relang()` (whole sentences without values only).
- A pack's own content (state names, script names, button names, `words.device`…) belongs to the pack and is not in the platform's catalogs.

## Not translated

- Commands sent by chat bot buttons (`cmd:停下來 全部`) are read by the program and marked `# i18n: keep`.
- Command words people type: Chinese is always understood, and the English and Simplified Chinese words too (`VERBS` in `notify/commands.py`).
- The program never decides anything by comparing translated text; it uses codes or flags (e.g. `dec["done"]`, `dec["wait"]`, `level` = suggest / ok / later). Where it must read back a sentence it wrote, it cuts that sentence at its values in the current language (`automation/runner.py` `_around`).

## Tools

```
python -m tools.i18n extract      # every text to translate -> web/src/i18n/zh-TW.json, i18n/zh-TW.json
python -m tools.i18n check        # how many texts each language lacks or no longer uses
python -m tools.i18n todo [-v]    # Chinese not yet wrapped in t() / _()
node web/tools/i18n-wrap.mjs <file>          # web: wrap Chinese in t()
python -m tools.i18n_wrap <file> [--mark]    # server: wrap Chinese in _() (--mark: N_() for module-level tables)
```

## 简体中文

Converted from Traditional Chinese: `python -m tools.i18n_zhcn` (needs `pip install opencc-python-reimplemented`, used by this tool only).
OpenCC turns Taiwanese usage into mainland usage; the FIX list in `tools/i18n_zhcn.py` then corrects the words it gets wrong for this platform, and quotes become “”. Run it again whenever the Traditional Chinese changes.

## 日本語 / 한국어

Translated by hand, from the English and the Chinese. Japanese keeps 「」, 、 and half-width `:()`, has no plurals, and reorders split sentences into Japanese word order. Korean uses ‘ ’ for names, `, ` for lists, particles written as `을(를) / 이(가) / 은(는) / (으)로`, and keeps the trailing spaces of split pieces. Both use English chat commands. Review by native speakers is welcome.

## Adding a language

1. Make sure the language is in `LANG_NAMES` (`web/src/i18n/index.ts`) and `NAMES` (`i18n/__init__.py`).
2. `python -m tools.i18n extract` for the current list of texts.
3. Translate with the glossary below into the two `locales/<lang>.json`. Keep every `{name}` as it is, and the leading / trailing spaces and line breaks of the original.
4. `python -m tools.i18n check` must show 0 missing; rebuild the web (`npm run build`).
