# 多語系(介面語言)

[English](i18n.md) · 繁體中文

## 機制

- 程式裡寫的是繁體中文,**中文本身就是翻譯的鑰匙**:
  - 網頁:`t('新增規則')`、`t('第 {n} 步', { n })`(`web/src/i18n/index.ts`)
  - 後端:`_("子腳本失敗")`、`_("第 {n} 步", n=3)`(`i18n/__init__.py`)
  - 模組層級的表(例如步驟名稱)用 `N_("…")` 標記,顯示的地方再用 `_()` 或 `tr(表)` 翻譯。
- 句子要整句寫在一段文字裡,值用名字帶入(`{name}`),讓語序不同的語言可以移動它們。不要把句子拆成幾段拼起來。
- 單複數:譯文可以寫 `{n|frame|frames}`,值是 1 時用前面那個字(例如 `{n} {n|time|times}`)。中文不用寫。
- 列舉與引號也要經過翻譯:`_("、").join(...)` / `t('、')`、`_("「{x}」", x=…)` / `t('「{x}」', { x })`,英文會變成 `, ` 和 `"x"`。
- 翻譯檔:
  - 網頁 `web/src/i18n/locales/<語言>.json`,後端 `i18n/locales/<語言>.json`,內容是 `{"中文": "譯文"}`。
  - 翻譯檔沒有的句子顯示中文,所以可以翻一部分就先用。
- 用哪個語言:
  - 網頁:每個瀏覽器自己選(側邊欄最下面、操作面板右上角),送出的每個請求都帶 `X-Lang`,後端組的句子也跟著換。
  - 執行端(執行紀錄、通知、聊天 Bot 的回覆):這台電腦的設定 `inspector.json` 的 `"language"`,在「執行 › ⚙ 執行設定」改。
- 執行端寫進狀態檔的固定字(停下來、暫停、誰按的…)用的是機器語言;伺服器回傳時用 `i18n.relang()` 換成頁面的語言
  (只限不帶值的整句)。
- 方案包(例如狀態名稱、腳本名稱、按鈕名稱、`words.device`)是方案包自己的內容,不在平台的翻譯檔裡。

## 不翻譯的東西

- 聊天 Bot 按鈕送出的指令(`cmd:停下來 全部`)是給程式讀的,標了 `# i18n: keep`。
- 使用者打的指令字:中文永遠認得;換成其他語言時,也認得那個語言的寫法(`notify/commands.py` 的 VERBS 另有英文)。
- 程式不可以拿翻譯過的文字做判斷。要判斷就用代碼或旗標(例如 `dec["done"]`、`dec["wait"]`、`level` = suggest / ok / later)。

## 工具

```
python -m tools.i18n extract      # 列出所有要翻的句子 → web/src/i18n/zh-TW.json、i18n/zh-TW.json
python -m tools.i18n check        # 各語言缺幾句、多出幾句
python -m tools.i18n todo [-v]    # 還沒包進 t() / _() 的中文
node web/tools/i18n-wrap.mjs <檔案>          # 網頁:把中文包進 t()
python -m tools.i18n_wrap <檔案> [--mark]    # 後端:把中文包進 _()(--mark:模組層級的表標 N_())
```

## 簡體中文

由繁中自動轉換:`python -m tools.i18n_zhcn`(需要 `pip install opencc-python-reimplemented`,只有這個工具用到)。
OpenCC 會把台灣用語換成大陸用語(視窗→窗口、程式→程序、預設→默认、資料→数据…),`tools/i18n_zhcn.py` 的 FIX
再修正它在這個平台用錯的詞(仿真器→模拟器、调度→定时任务、接口→界面、高端→高级、激活→启用…),引號改成 “”。
繁中有改動時重跑一次即可。聊天 Bot 的指令字另外收了簡體寫法(`notify/commands.py` VERBS)。

## 日本語

人工翻譯(參考英文)。用語:腳本=スクリプト、子腳本=サブスクリプト、守門規則=ガードルール、情境=シチュエーション、
試跑=試行、正式=本番、停下來=停止、暫停=一時停止、繼續=再開、收尾=後片付け、部署=デプロイ、素材庫=素材ライブラリ、
找圖=画像検索、保留裝置=保留デバイス、回答問題=問題に回答、成績與錯題=成績と誤答、自動標註=自動ラベル付け、
操作面板=操作パネル。保留「」、、和半形的 :()。日文不分單複數,不用 `{n|…|…}`;拆成幾段的句子照日文語序重排各段。
聊天指令字(menu/status/stop…)用英文。

## 한국어

人工翻譯(參考英文和日文)。用語:腳本=스크립트、子腳本=서브스크립트、守門規則=가드 규칙、情境=상황、試跑=시험 실행、
正式=실제 실행、停下來=정지、暫停=일시정지、繼續=재개、收尾=마무리、部署=배포、素材庫=소재 라이브러리、找圖=이미지 찾기、
保留裝置=보류 기기、回答問題=문제 풀기、成績與錯題=성적과 오답、自動標註=자동 라벨링、操作面板=조작 패널。
「」改成 ‘ ’,、改成「, 」;名稱後的助詞寫成「을(를)、이(가)、은(는)、(으)로」。韓文詞之間要空格:英文譯文結尾有空格的段落,
韓文譯文也要保留結尾空格(拆段的句子才接得起來)。聊天指令字用英文。

## 新增一個語言

1. 在 `web/src/i18n/index.ts` 的 `LANG_NAMES` 和 `i18n/__init__.py` 的 `NAMES` 確認有這個語言(目前有 zh-TW、en、zh-CN、ja、ko)。
2. `python -m tools.i18n extract` 取得最新的句子清單。
3. 照下面的用語表翻譯,存成兩個 `locales/<語言>.json`。`{name}` 要原樣保留;開頭、結尾的空白和換行照原文。
4. `python -m tools.i18n check` 確認缺 0 段,重建網頁(`npm run build`)。
