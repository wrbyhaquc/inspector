# 腳本怎麼設計

[English](scripts.md) · 繁體中文

Inspector 的自動化只有一種寫法:**「如果 … 就依序做 …」的卡片**,加上一套共用的**步驟**。
主腳本、全域守門規則、子腳本都用同一種卡片和同一套步驟,差別只在**什麼時候檢查「如果」**。

## 三種腳本

| | 是什麼 | 「如果」什麼時候檢查 |
|---|---|---|
| **全域守門規則** | 每台、每個主腳本之前都先看的一份規則 | 每秒檢查,由上往下,第一條成立的就做 |
| **主腳本** | 日常的主流程,分成幾個「情境」(例如 工作中、回到起點) | 每秒檢查**目前情境**的規則,由上往下,第一條成立的就做 |
| **子腳本** | 一段做到完的流程(回到起點、切換帳號、異常復原…) | 依序執行,**走到這一步時檢查一次**,看完就往下走 |

### 每秒檢查(主腳本、守門規則)

- 系統每秒從上往下看一次規則清單,第一條成立的規則就依序做它的步驟;下面的規則這次不看。
- 所以**順序就是優先順序**:越上面越優先。守門規則永遠比所有主腳本優先。
- 不用自己寫「重複」:只要條件一成立,下一秒就會被抓到(例如做到一半水位降到 30% 以下)。
- 每條規則可以設:
  - **冷卻**:做完後多久內不再做。
  - **每小時 / 每天最多幾次**。
  - **緊急**:第一次看到就做(不等第二次確認),而且可以打斷這台正在跑的子腳本。
- 規則的條件判斷不出來(模型沒把握)時,不會往下跳到下一條,而是這次先不動作。

### 走到才檢查(子腳本)

- 步驟由上往下一步一步做。「如果 / 否則如果 / 否則」在走到那一步時看一次,選一條路做完就往下走,之後不會再回頭看。
- 要「等到某個畫面出現」用「等到條件成立」,或在點擊之後設「做完之後:等到 …」。
- 要反覆做直到某個狀況用「重複直到」;失敗要重來用「失敗就重試」。

## 共用的步驟

規則的「就依序做」、情境的「進入時做」、子腳本的步驟,都用同一套步驟:

- **操作畫面**:點擊、長按、滑動、返回鍵、輸入文字、在清單中找到並點擊、走到地圖上的位置、啟動 App、擷取清單。
  點擊類步驟可以設「做完之後」:等幾秒,或等到畫面 / 數字符合條件。
- **等待**:等待秒數、等到條件成立。
- **判斷與重複**:如果…否則、重複直到、對每一個…、失敗就重試。
- **呼叫與結束**:呼叫子腳本(它失敗時:整個失敗 / 繼續下一步 / 停下這台)、照目錄項目做、結束(成功)、結束(失敗)、停下這台、切換情境。
- **溝通**:通知、問使用者、送到輸出。
- **記錄**:設定變數。
- **規則專用**:原地等著(不動作,也不讓下面的規則做)、暫停其他腳本(只有守門規則)。

有些步驟只在特定地方有意義:

- **切換情境**:只在主腳本的規則和情境進入時(子腳本、守門規則沒有情境)。
- **原地等著 / 暫停其他腳本**:只能是一條規則唯一的一步。

## 目錄:從很多項裡選一項,每一項有自己的做法

**目錄**(素材庫 › 目錄)是一份可以選的項目,用資料夾整理。每一項寫好「做這一項是什麼意思」:依序呼叫哪些子腳本、各帶什麼參數(例如先進去、再選區、再走過去)。
同一個目錄裡的項目可以用不同的子腳本,例如要去的地點,有的用地圖傳送,有的要先進某個地方再往裡走;或要打掃的房間,各有各的路線。

- 讓使用者選:在使用者設定加一個「目錄的一項」。它會像其他選項一樣出現在操作面板和聊天 Bot,照目錄的資料夾分好。
- 腳本裡用 **照目錄項目做**:做選到的那一項(使用者設定的值、文字參數,或固定某一項),也就是依序呼叫那一項的子腳本。
- 項目也可以設 **怎麼看出已經在那裡**(條件,和「如果」一樣)。設了之後會先看:已經在那裡就不用做(不會再跑一趟、再花一次費用);
  做完後等它成立,沒等到就算這一項失敗,呼叫的地方可以改做別的。
- 新增一個項目只要填目錄,不用改腳本。

## 走到地圖上的位置

**走到地圖上的位置**給「地圖上看得到自己、用搖桿移動」的畫面用(遊戲、機器人的平面圖)。它一段一段走:打開地圖、看「自己」的記號在哪、關掉地圖、往下一個點推一下搖桿,再來一次。

- **基準圖示**:地圖上一個固定的圖示(找圖的按鈕)。點都從它算起,所以地圖打開時跟著自己移動也沒關係。
- **「自己」**:記號的顏色,和地圖在畫面上的範圍(找最大的一塊這種顏色)。
- **要走到的點**,依序:例如橋頭、橋尾、橋後面的空地。每個點可以設「多近算到」。
- **搖桿**:中心和推多遠;遊戲允許的話,「直接按住邊緣」比較快。
- 可以設 **這個條件成立就算到了**:例如「地點名稱顯示已經離開安全區」。

往哪推會往地圖的哪邊走、推多久走多遠,都是邊走邊學,不用校正。推了卻幾乎沒動(被東西擋住)時,會用短推往兩側試;一直卡住就算這一步失敗。

## 條件

- 一張卡的條件分成一組或多組:**同一組裡全部成立**才算(而且),**任何一組成立**就算(或者)。
- 條件種類:狀態(模型或規則判斷出的值)、剛變成、一段時間內幾次、變化量、時段、總是、變數、距離上次、其他裝置、看得到按鈕、**比較兩個數字**。
- 「比較兩個數字」的兩邊都可以是數字、畫面上讀到的數字、使用者設定、變數,或把幾個加起來,例如
  `庫存 ≥ 今天的訂單數 + 設定「安全庫存」`。
- 通知、失敗訊息等文字裡可以寫 `{代號}`,執行時帶入參數、變數、畫面上讀到的數字或使用者設定的值。

## 停下來與暫停

- **停下這台 / 停下來**:這台的腳本和情境全部停止;按「繼續」後從頭開始(情境回到起點、條件重新計算)。
- **暫停**:停在原地;按「繼續」後從同一個情境、同一步接著做。
- 一台、一個標籤(#標籤)、全部、規則觸發,都是同一套機制。
- **有人操作**:偵測到有人碰觸這台的螢幕,就自動**暫停**;設定的秒數內沒有再碰,就自動**繼續**(同一個情境接著做,暫停的時間不算進情境的停留時間)。
  正在跑的排程會等,之後從同一步接著做;規則叫起來的子腳本會取消(人已經動過畫面),之後由規則重新判斷、需要時再叫一次。
